# Examples

This folder contains example resource files generated by CSharpRisohEditor.

## sample.rc

A sample Win32 Resource Script file containing:

- **Dialog**: A simple dialog with OK and Cancel buttons
- **Menu**: A menu with File and Edit submenus
- **String Table**: Application strings (name, copyright, version)
- **Accelerators**: Keyboard shortcuts (Ctrl+O, Ctrl+S)

This file can be compiled with a Windows resource compiler (RC.EXE) or used as a reference for creating your own resources.

## Usage

You can generate this file by running:

```bash
dotnet run --project ../src/CSharpRisohEditor.CLI
```

The generated RC file follows standard Win32 resource script format and is compatible with:
- Microsoft Resource Compiler (rc.exe)
- MinGW windres
- Original RisohEditor
